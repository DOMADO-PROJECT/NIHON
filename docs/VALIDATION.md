### 측정 조건

Playwright로 Chrome 158.0.8127.38을 390×844 터치 화면으로 실행했습니다.<br>
매회 새 브라우저 컨텍스트에서 서비스 워커를 차단하고 MP3 요청을 300ms 늦췄습니다.<br>
2인 문장이 화면에 뜨고 800ms가 지난 뒤 문장을 눌렀습니다.<br>
재생이 시작되면 곧바로 상대 답변을 눌렀습니다.<br>
MY에서는 아이다 시게루를 고른 뒤 800ms 기다렸다가 예문을 눌렀습니다.<br>
각 조건을 다섯 번 반복해 중앙값을 구했습니다.<br>

이 수치는 재생 버튼을 누른 뒤 사용자가 기다린 시간의 중앙값입니다.<br>
회화에 들어가 곧바로 누르거나 데이터 절약 모드를 켜 두면 첫 다운로드를 기다릴 수 있습니다.<br>
